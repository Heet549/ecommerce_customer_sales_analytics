# E-Commerce Customer & Sales Analytics

End-to-end Data Analytics project using **SQL, Python/Pandas, and Excel** to analyze a synthetic e-commerce dataset and generate business insights.

## Key Highlights

* Analyzed **20,000 orders** and **60,818 units** worth **$11.92M** in revenue.
* Performed **sales, customer, product, review, and customer lifecycle analysis**.
* Identified a **68.26% repeat-customer rate** and **2,528 repeat-lapsed customers**.
* Built an **Excel dashboard** with KPI reporting, analysis tables, and charts.
* Validated **21 SQL vs Pandas metrics — 21/21 matched**.

## Tech Stack

**SQL | Python | Pandas | NumPy | Excel | Jupyter Notebook**
